## Краткая справка
### Указатели и ссылки

Пусть есть тип `T`, тогда тип `T*` - указатель на `T`. То есть, переменная типа `T*` может содержать в себе адрес объекта типа `T`. 

Пример:
```cpp
int a = 123;
int* p = &a;
```
`p` хранит адрес `a`; `&` - оператор взятия адреса.

Основная операция - разыменовывание указателя (унарный префиксный оператор `*`), то есть обращение к объекту на который указывает указатель.

Пример:

```cpp
int a = 45;
int* p = &a;
int b = *p;
```

`p` указывает на `a` которое хранит значение `45`, поэтому в `b` присваивается значение `45`.

#### `nullptr`
`nullptr` - нулевой указатель, то есть указатель не указывающий ни на какой объект. Значние `nullptr` можно присвоить в указатель любого типа.

#### Массивы
Пусть есть тип `T`, тогда тип `T[size]` - массив из `size` элементов типа `T`.

```cpp
int arr1[5];
int arr2[] = {1, 2, 3, 4}; // размер будет выведен из количества элементов в квадратных скобках
```

Размер задаётся на этапе компиляции, поэтому указываем либо литерал, либо переменную помеченную `const`. Есть компиляторные расширения позволяющие задавать размер в рантайме - VLA. Мы их использовать не будем, так как не входит в стандарт C++. Если нужен массив динамического размера - используем `std::vector`.

Обращение к элементам массива либо через `[]`, либо через указатель. Проверок на корректность индекса нет. Вышли за границы массива - получили UB.

Массивы распадаются до указателей на первый элемент, не копируются (необходимо руками копировать все элементы), а также нельзя присвоить один массив в другой.

Строковые литералы на самом деле массивы типа `char*`, поэтому ведут себя не так удобно как нормальные строки `std::string`.


#### Арифметика указателей
Арифметика указателей работает только в рамках 1 массива, при этом обычные переменные (не массивы) считаются в этом контексте массивами из 1 элемента. Попытались разыменовать указателей указывающий за границы массива - получили UB. Попытались произвести арифметику используя указатели на разные массивы - получили UB. Попытались взять (даже не разыменовывая) указатель за пределы массива - UB с единственным исключением - иметь указатель на элемент за последним элементов массива можно.

#### Константные указатели
```cpp
const int* cp; // указатель на const int
int* const pc; //константный указатель на int
const int* const cpc; // константный указатель на const int
```


#### Ссылки
Ссылка - другое имя для объекта.

Отличие ссылки от указателя:

1 - Синтаксис работы с ссылками не отличается от синтаксиса работы с объектами

2 - Ссылка всегда указывает на объект которым она была проинициализирована. Нулевых ссылок не существет.
